Tomada de decisão baseada em dados

Tomar decisões examinando a evidência antes de formar a conclusão, e de modo que ela possa mudá-la.

Também chamado de Decisões baseadas em evidência

O teste não é se os dados aparecem no documento de decisão. É se os dados poderiam ter produzido uma decisão diferente. Uma organização que reúne a evidência depois de escolher não é orientada a dados, é decorada com dados, e todos os envolvidos percebem a diferença. Ser genuinamente orientado a dados também exige aceitar que algumas decisões têm evidência insuficiente e dizer isso, em vez de vestir um julgamento como análise.

Na prática. Escreva, antes da análise, qual resultado faria você mudar de ideia. Esse único hábito converte um exercício de confirmação em uma decisão, e é gratuito.

Onde dá errado. A expressão é usada para dizer "temos painéis". Painéis são oferta. Uma cultura de decisão é demanda, e as duas são independentes — há muitas organizações com reporte excelente do qual nenhuma decisão jamais dependeu. Um trabalho de governança que só melhora a oferta não vai mover isso em nada.

Termos relacionados

  • Cultura de dadosO conjunto de hábitos que determina se a evidência muda o que uma organização faz — inclusive quando contraria quem está no comando.
  • Alfabetização de dadosA capacidade de ler, questionar, interpretar e argumentar com dados bem o bastante para tomar uma decisão com eles.
  • Fonte única da verdadeO único lugar designado como autoritativo para um dado específico, do qual todo o resto deriva ou ao qual todo o resto cede.
  • Qualidade de dadosO grau em que os dados são adequados ao propósito para o qual alguém os está usando — o que significa que a qualidade é sempre relativa a um uso.
