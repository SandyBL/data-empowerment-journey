Glossário de governança de dados

Todos os termos em que uma conversa de governança de dados tropeça, definidos em linguagem clara: o que significam, como são usados de verdade e o erro que as pessoas cometem com eles. Escrito para quem precisa explicar isso numa reunião, não para passar em uma prova de certificação.

Fundamentos

6 termos
DAMA-DMBOK
O framework de referência da DAMA International para gestão de dados: onze áreas de conhecimento organizadas ao redor da governança de dados.
Domínio de dados
Uma área temática delimitada de dados — cliente, produto, funcionário, contrato — pela qual um único dono pode razoavelmente responder.
Gestão de dados
O trabalho de construir e operar os sistemas, processos e controles que sustentam os dados por todo o seu ciclo de vida.
Governança de dados
O sistema de direitos de decisão e responsabilidades sobre os dados: quem pode decidir o quê sobre quais dados, e com que base.
Padrão de dados
A regra concreta e verificável que diz como uma política é satisfeita: formato, valores permitidos, nomenclatura, tolerância.
Política de dados
Uma declaração curta e vinculante do que a organização exige dos seus dados, aprovada por alguém com autoridade para exigir.

Papéis e responsabilidades

5 termos
Conselho de governança de dados
O fórum permanente de donos dos dados que resolve as decisões que nenhum domínio consegue tomar sozinho.
Data steward
A pessoa que faz o trabalho diário de governança em um domínio: definições, regras, incidentes de qualidade e as perguntas que mais ninguém sabe responder.
Direitos de decisão
O registro explícito de qual papel decide, qual é consultado e qual apenas é informado — decisão por decisão, não em geral.
Dono dos dados
A única pessoa responsável por um domínio de dados: quem decide, aprova e responde por ele, e tem orçamento para agir.
Stewardship de dados
A prática e a rede de pessoas por meio das quais as decisões de governança de fato chegam aos dados.

Metadados e catálogo

5 termos
Catálogo de dados
O inventário pesquisável de ativos de dados, com significado, dono, linhagem e qualidade associados.
Gestão de dados mestres
A disciplina de manter um único registro autoritativo das entidades que todo o negócio compartilha: cliente, produto, fornecedor, funcionário.
Glossário de negócio
As definições acordadas e com dono dos termos sobre os quais a organização reporta: um único significado por termo, com um nome por trás.
Linhagem de dados
O caminho rastreável de um valor desde onde se originou até onde é usado, incluindo cada transformação no percurso.
Metadados
A camada descritiva em torno de um ativo de dados: o que significa, de onde veio, quem é o dono e como pode ser usado.

Qualidade de dados

6 termos
Custo da má qualidade de dados
O dinheiro e o tempo mensuráveis que uma organização perde por dados errados, ausentes, atrasados ou duplicados.
Dimensões de qualidade de dados
Os eixos padrão pelos quais os dados podem falhar: completude, exatidão, consistência, oportunidade, validade e unicidade.
Elemento de dados crítico
Um campo de dados cuja falha tem consequência material — regulatória, financeira, operacional ou reputacional — e que por isso é governado primeiro.
Perfilamento de dados
Examinar os dados reais para descobrir o que há de fato neles: distribuições de valores, taxas de nulos, formatos, atípicos e relações.
Qualidade de dados
O grau em que os dados são adequados ao propósito para o qual alguém os está usando — o que significa que a qualidade é sempre relativa a um uso.
Regra de qualidade de dados
Um teste executável sobre os dados, com um limite definido e uma pessoa responsável que age quando ele falha.

Alfabetização e cultura

3 termos
Alfabetização de dados
A capacidade de ler, questionar, interpretar e argumentar com dados bem o bastante para tomar uma decisão com eles.
Cultura de dados
O conjunto de hábitos que determina se a evidência muda o que uma organização faz — inclusive quando contraria quem está no comando.
Tomada de decisão baseada em dados
Tomar decisões examinando a evidência antes de formar a conclusão, e de modo que ela possa mudá-la.

Maturidade e medição

3 termos
Maturidade de dados
Com que confiabilidade e repetibilidade uma organização gerencia seus dados: se o resultado depende do processo ou da pessoa.
Modelo de maturidade de dados
Uma escala estruturada para avaliar capacidades de dados, normalmente de ad hoc a otimizado, usada para diagnosticar onde investir.
Modelo operacional de governança de dados
O arranjo escrito de quem governa o quê, como as decisões são tomadas e como o trabalho chega aos dados no dia a dia.

IA, privacidade e risco

3 termos
Classificação de dados
Rotular os dados pelo grau de sensibilidade, para que as regras de manuseio sejam aplicadas automaticamente em vez de lembradas.
Governança de IA
Os controles sobre como modelos são construídos, aprovados, monitorados e desativados — a maioria deles controles de dados com outro nome.
Informação pessoal identificável
Dados que identificam uma pessoa viva, diretamente ou em combinação com outros dados a que quem os detém tem acesso.

Arquitetura e produtos de dados

2 termos
Fonte única da verdade
O único lugar designado como autoritativo para um dado específico, do qual todo o resto deriva ou ao qual todo o resto cede.
Produto de dados
Um conjunto de dados curado, documentado e com dono, construído e mantido para consumidores conhecidos e com um nível de serviço associado.
