Um playbook não é uma metodologia. Uma metodologia diz qual é o estado final ideal; um playbook diz o que fazer na segunda-feira quando você não tem orçamento, não tem mandato e tem um diretor que ouve você.

Estes dois foram escritos para a segunda-feira.

{{PLAYBOOKS}}

## O playbook de governança de dados

É a sequência que eu uso para levar um programa do zero a um primeiro domínio funcionando: como escolher o domínio, como encontrar os [elementos de dados críticos](/pt/glossary/critical-data-element/) que existem dentro dele, como conseguir que a [propriedade](/pt/glossary/data-owner/) seja aceita em vez de atribuída, e o que a primeira reunião do comitê deve ter na pauta para que as pessoas saiam tendo decidido algo.

É deliberadamente estreito. Ele não tenta cobrir onze áreas de conhecimento, porque um programa de primeiro ano que tenta cobrir onze áreas de conhecimento produz um documento de framework e nenhuma mudança de comportamento. Um domínio, feito de forma visível, compra o segundo para você.

## O playbook de governança de IA

A maioria das conversas sobre governança de IA começa no modelo e vai para trás, e é por isso que elas travam. As perguntas interessantes são quase todas perguntas de dados: com o que isso foi treinado, quem tinha autorização para aprovar aquilo, o que acontece quando alguém pede que o seu registro seja apagado, e se você consegue dizer, por escrito e a um regulador, de onde veio uma determinada saída.

Este playbook vai para frente a partir do dado: [classificação](/pt/glossary/data-classification/) antes da ingestão, [linhagem](/pt/glossary/data-lineage/) como pré-condição e não como algo desejável, e os direitos de decisão específicos de que um órgão de [governança de IA](/pt/glossary/ai-governance/) precisa e que um comitê de governança de dados ainda não tem. Ele assume que você tem alguma governança em pé; se não tiver, leia o outro primeiro.

## O framework de diagnóstico de maturidade

O framework por trás do [scorecard](/pt/maturity-assessment/), como documento adaptável. Útil se você preferir rodar o diagnóstico você mesmo, com as suas próprias palavras, em vez de mandar a sua equipe para um formulário no site de outra pessoa.

## Usando com um grupo

Os dois playbooks funcionam como leitura para um comitê de governança, e os dois funcionam melhor quando a leitura é seguida de uma discussão. Se você quiser essa discussão encenada em vez de esperada, os [simuladores de cenários](/pt/resources/) colocam uma sala dentro das escolhas, e o [formato de workshop](/pt/workshops/) roda com os seus próprios sistemas e um relatório para o facilitador no fim.
